# Mern Training

<div align="center">

  A collection of small HTML, CSS, and JavaScript practice projects built while learning front-end fundamentals.

</div>

## Overview

This repository is a static front-end playground made up of multiple mini pages and experiments. It includes layout exercises, interaction demos, form-style UI, and DOM scripting practice. Each page is self-contained, so you can open the HTML file directly in a browser and explore a specific concept.

## What’s Inside

- Responsive layout experiments
- Interactive UI demos
- DOM manipulation practice
- Event handling examples
- Styling and animation exercises
- A small to-do list app

## Project Pages

- `index.html` - simple popup / starter page
- `admin.html` - admin-style layout demo
- `dynamiccard.html` - card-based UI practice
- `faq.html` - FAQ / accordion-style layout
- `grid.html` - CSS grid practice
- `iffts.html` - layout or flexbox-style exercise
- `keyboardcount.html` - keyboard event counter
- `loginpage.html` - login form UI
- `mediaquery.html` - responsive design exercise
- `Modal.html` - modal window demo
- `mouse.html` - mouse event demo
- `newsite.html` - text manipulation demo
- `scrollevent.html` - scroll interaction demo
- `span.html` - typography / span styling exercise
- `to-do-list.html` - interactive to-do list app
- `transition.html` - CSS transition demo

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How To Run

1. Clone the repository.
2. Open the project folder in VS Code or any editor.
3. Open any `.html` file directly in a browser, or use a live server extension for easier preview.

No build step or package installation is required.
